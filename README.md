# PotionsAndDungeons

## Версия для Windows

Распакуй ZIP целиком и запусти `PotionsAndDungeons.exe`. Среда Java входит в архив. Сохранения и настройки находятся в `%LOCALAPPDATA%\PotionsAndDungeons`.

Для сетевой игры с Android используй один и тот же режим на обоих устройствах. Например, в режиме VPN оба устройства подключаются к одной сети Tailscale, а гость вводит VPN IPv4 ведущего и код комнаты.

### Сборка для ПК

Для запуска из исходников нужен JDK 21. В PowerShell из корня проекта:

```powershell
.\gradlew.bat -p desktop run
```

Для переносимого архива Windows x64 нужны Go, zip и распакованная Windows x64 JRE 21:

```sh
bash gradlew -p desktop installDist -PdesktopTarget=windows
bash desktop/pack-windows.sh /path/to/windows-jre PotionsAndDungeons-1.7.0-Windows-x64.zip
```

## Обновления

В меню **Настройки → Обновления** можно проверить версию и включить автоматическое скачивание. В переносимой сборке Windows скачанное обновление применяется при следующем запуске через `PotionsAndDungeons.exe`. На Android установка APK подтверждается в системном окне.

Для GitHub Releases используй тег `vX.Y.Z` и файлы `PotionsAndDungeons-X.Y.Z.apk` и `PotionsAndDungeons-X.Y.Z-Windows-x64.zip`. APK должен иметь повышенный `versionCode` и ту же подпись, что предыдущий выпуск. Вместе с ними можно прикрепить `update-manifest.json`, чтобы проверка работала и при ограничении доступа к GitHub API.

```powershell
.\scripts\New-UpdateManifest.ps1 -Version 1.7.0
```

## Игра через VPN

Подключите все устройства к одной VPN-сети (например, Tailscale) и откройте **Сетевая игра → VPN**. Ведущий копирует свой IPv4-адрес из VPN-приложения, вводит его и создаёт комнату. Остальные вводят VPN IPv4 ведущего и шестизначный код комнаты.

Чтобы собрать APK, который устанавливается рядом с обычной версией:

```sh
bash gradlew :app:assembleDebug -PvpnTest
```

## Игра через интернет

Онлайн-комната соединяет 2–4 устройства через общий сервер. Ведущий запускает партию, остальные подключаются по шестизначному коду. Гость может переподключиться после обрыва связи, пока комната ведущего открыта.

### Запуск сервера

На сервере с Python 3.11+ нужен публичный DNS-адрес и действующий TLS-сертификат для этого адреса. Открой входящий TCP-порт 8443 и запусти из корня проекта:

```sh
python3 server/relay.py --port 8443 --cert /path/to/fullchain.pem --key /path/to/privkey.pem
```

Сервер должен работать всё время, пока доступны онлайн-комнаты. После перезапуска открытые комнаты закрываются.

### Подключение из приложения

1. Открой **Сетевая игра → Интернет**.
2. Введи домен сервера. Для порта, отличного от 8443, используй формат `домен:порт`.
3. Создай комнату и передай код друзьям. Они используют тот же сервер и вводят код.

Чтобы сразу задать адрес для всех игроков при сборке APK, передай его Gradle:

```sh
bash gradlew :app:assembleDebug -PrelayEndpoint=play.example.com:8443
```
